# PCOS Metabolic Syndrome Prediction

## Overview

This project focuses on the analysis and prediction of Polycystic Ovary Syndrome (PCOS) and metabolic health conditions using machine learning techniques. The system aims to identify patterns in clinical and lifestyle data to support early detection and risk assessment.

## Objectives

* Analyze PCOS-related health parameters.
* Identify metabolic risk factors associated with PCOS.
* Build predictive machine learning models for disease classification.
* Evaluate model performance using standard metrics.
* Provide insights for early diagnosis and healthcare decision-making.

## Dataset

The dataset contains various medical and health-related attributes such as:

* Age
* Weight
* BMI
* Blood Pressure
* Hormonal Parameters
* Glucose Levels
* Insulin Levels
* Menstrual Cycle Information
* Other Clinical Features
